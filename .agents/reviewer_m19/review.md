  - `disconnectedCallback()` 内で `this._unsubI18n()` を適切に呼び出し、メモリリークを防止しています。
  - `card()`、`render()`、カテゴリチップテンプレート内において、`getLocale() === 'ja'` による判定およびオプショナルチェイニング・null合体演算子 (`name_ja ?? name`) により日本語表示を正しく優先表示しています。

## 4. 敵対的ストレス判定（Adversarial Review / Critic）

### シナリオ1: 全角・半角・ひらがな・カタカナの揺らぎ検索
- **検証**: 現状の `filtered()` および `fuzzyMatch()` は JavaScript の `includes()` を用いた部分一致検索です。
- **評価**: 「シミュレータ」等の標準カタカナ・漢字表現では完全にヒットします。全角・半角やひらがな・カタカナの自動正規化（NFKC正規化等）は含まれていませんが、実用上十分な精度であり、欠陥ではありません。将来的な改善案として記録します。

### シナリオ2: 将来的なアプリ追加時のフォールバック動作
- **検証**: 仮に将来 `name_ja` や `summary_ja` が未定義のアプリが追加された場合。
- **評価**: `isJa && app.name_ja ? app.name_ja : app.name` および `app.name_ja ?? app.name` により、安全に英語表記へフォールバックされるため、画面崩れやエラーは発生しません。
